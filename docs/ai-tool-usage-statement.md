# AI 工具使用说明

本项目允许使用 AI 辅助工具提高开发和写作效率，但最终提交内容必须由项目负责人理解、筛选、修改和整合。AI 工具不能替代项目构思、代码解释、调试责任和最终提交责任。

## 建议放入报告的声明

本项目在开发过程中使用 AI 辅助工具进行代码样板生成、局部调试建议、Prompt 设计讨论、功能表整理和报告文字润色。所有核心功能、系统结构、数据模型和最终报告内容均由本人理解、筛选、修改和整合后形成；AI 工具未替代本人完成项目构思、代码解释、调试责任和最终提交责任。

## 使用范围

| 使用环节 | 允许用途 | 人工责任 |
|---|---|---|
| 代码开发 | 生成样板代码、解释错误、提出局部优化建议 | 阅读并理解代码，修正不适合项目的实现 |
| 调试验证 | 协助分析报错、整理测试步骤 | 真实运行命令并记录结果 |
| Agent 设计 | 讨论 Prompt、工具调用、记忆与规划链路 | 选择符合项目边界的设计并写入源码 |
| 报告写作 | 润色表达、调整结构、生成清单初稿 | 核对事实、补充截图和运行证据 |
| 演示材料 | 整理视频脚本、功能亮点和提交清单 | 确认演示流程与实际系统一致 |

## 禁止行为

- 不得直接提交无法解释的 AI 生成核心代码。
- 不得隐瞒 AI 工具参与过代码、Prompt 或报告整理。
- 不得编造功能、运行结果、公网链接、测试结果或数据来源。
- 不得把包含密钥、个人隐私或未脱敏目标的内容提交给外部服务。

## 提交前检查

提交前运行：

```powershell
pnpm check:submit
```

该脚本会检查 `node_modules`、`.env`、日志目录、构建缓存和明显密钥痕迹，帮助避免提交包不合规。
